# Rime website

Static website: open index.html or serve this directory with Python 3.

- Rime Friends: rime-paint-kids.html (ages 3–10).
- Rime Studio: rime-paint-adult.html (ages 11+).
- Rime Pulse: proposed concept only.

The gh-pages branch contains the publishable site. If GitHub Pages is disabled,
open repository Settings → Pages → Deploy from a branch → gh-pages → / (root).
There are no API keys or build dependencies. Login is local demo only.
Artwork is embedded. Browser data is local to each origin; download important artwork.
